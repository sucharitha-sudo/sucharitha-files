# Chatbot Documentation

## Introduction

I worked for a client **Haz Advizors**, creating a user guide and video script explaining how to create a chatbot using Google's Dialogflow platform.

The documentation was designed to help users understand the chatbot creation process through clear, step-by-step instructions and video-based guidance.

## Deliverables

* User Guide: Developed a step-by-step user guide explaining how to create a chatbot using Google Dialogflow.
* Video Script: Created a video script outlining the chatbot creation process to support visual learning and demonstrate the platform's functionality.
